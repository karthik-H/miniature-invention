# Ecommerce service

Customers can create an account and sign in. Signed-in users can add products to the catalog. Anyone can browse products.

## Accounts

- Register with an email and password. Each email can be used once.
- Sign in with that email and password.
- A signed-in user can update the catalog. Passwords stay private.

## Catalog

- Add a product with a name, description, price, and product code.
- Each product code can be used once.
- View the full catalog.
- Open a single product by its identifier.

Catalog changes are available only after sign-in. Browsing the catalog is open to everyone. Product and account information is kept only while the service is running.
